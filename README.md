# Uniquee Food — Organic Grocery & Pure Food E-Commerce Platform

> **"Quality Inside, Perfection Outside"**  
> *"Pure Food, Pure Life" & "Good Food, Better Life"*

**Uniquee Food** is a modern, high-converting organic food and pure grocery e-commerce web platform crafted for health-conscious food lovers. Designed with a custom artisan color palette (**Cosmic Latte**, **Mocha Cream**, **Deep Burgundy**, and **Organic Leaf Accent**), seamless dual-payment integration (Stripe & Cash on Delivery), robust role-based access control (Customer & Single Admin), and complete order/inventory management.

## 🛠️ Technology Stack
- **Frontend:** React 19 / Vite, Tailwind CSS, Lucide Icons, Framer Motion, Axios, React Router v6, Sonner & React Hot Toast
- **Backend:** Node.js, Express.js, MongoDB & Mongoose ODM, JSON Web Tokens (JWT)
- **Authentication:** Firebase Auth (Email/Password + Google Sign-In) with Backend JWT verification
- **Payments:** Stripe Checkout (Credit/Debit Card) & Cash on Delivery (COD)
- **Image Cloud:** ImgBB API Integration for rapid client/admin uploads

---

## 🚀 Getting Started

### 1. Prerequisites
- Node.js (v18+)
- MongoDB Database (Local or Atlas)
- Firebase Project credentials

### 2. Backend Server Setup
```bash
cd server
npm install
npm run dev
```

### 3. Frontend Client Setup
```bash
cd client
npm install
npm run dev
```
